{%- comment -%} Works out which files exist for one image and sets: img_path site-relative path without ?query (e.g. uploads/porch.jpg) img_q the ?query part, if any (cache-busters like ?v=2) img_base path without extension (img_b: the same, URL-safe) img_url URL for the image itself (prefixed for pages in subfolders) img_full best full-size URL for the lightbox (.webp sibling when it exists) img_cards true when -card-480/-card-960 thumbnails exist (made by tools/media/process_uploads.py) img_webp true when a .webp sibling exists img_w/img_h full-size dimensions, card_w/card_h dimensions of the 480 thumbnail Uploaded paths from Pages CMS start with "/" (e.g. /uploads/porch.jpg); the leading "/" is dropped so links stay relative and work under /fox-and-fable-design/ as well as on a custom domain. {%- endcomment -%} {%- unless all_files -%}{%- assign all_files = site.static_files | map: "path" | join: "|" | prepend: "|" | append: "|" -%}{%- endunless -%} {%- assign img_src = include.src | default: "" | strip -%} {%- assign first = img_src | slice: 0 -%} {%- if first == "/" -%}{%- assign img_src = img_src | slice: 1, 2000 -%}{%- endif -%} {%- assign parts = img_src | split: "?" -%} {%- assign img_path = parts[0] | default: "" -%} {%- if parts.size > 1 -%}{%- assign img_q = "?" | append: parts[1] -%}{%- else -%}{%- assign img_q = "" -%}{%- endif -%} {%- assign img_ext = img_path | split: "." | last | downcase -%} {%- assign cut = img_path.size | minus: img_ext.size | minus: 1 -%} {%- assign img_base = img_path | slice: 0, cut -%} {%- assign img_b = img_base | replace: " ", "%20" -%} {%- assign img_url = page.root | append: img_path | replace: " ", "%20" | append: img_q -%} {%- capture k %}|/{{ img_base }}-card-480.jpg|{% endcapture -%} {%- if all_files contains k -%}{%- assign img_cards = true -%}{%- else -%}{%- assign img_cards = false -%}{%- endif -%} {%- capture k %}|/{{ img_base }}.webp|{% endcapture -%} {%- if all_files contains k -%}{%- assign img_webp = true -%}{%- else -%}{%- assign img_webp = false -%}{%- endif -%} {%- if img_webp -%}{%- assign img_full = page.root | append: img_b | append: ".webp" | append: img_q -%}{%- else -%}{%- assign img_full = img_url -%}{%- endif -%} {%- assign dims = site.data.image_sizes[img_path] -%} {%- assign img_w = dims[0] -%}{%- assign img_h = dims[1] -%} {%- capture ck %}{{ img_base }}-card-480.jpg{% endcapture -%} {%- assign cdims = site.data.image_sizes[ck] -%} {%- assign card_w = cdims[0] | default: 480 -%}{%- assign card_h = cdims[1] | default: 600 -%}
